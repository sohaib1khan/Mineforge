# Connecting from phone and PC

1. Open **Minecraft Bedrock** (phone, Windows, Console with Bedrock).
2. Go to **Servers → Add Server** (or Play → Servers).
3. Enter a name, your public hostname or IP, and port **19132**.
4. Save and join.

MineForge’s Bedrock container uses **NetherNet** transport. Signaling uses **TCP 19132**; game traffic uses a **UDP** range (see Port forwarding).

On the same LAN you can often use the host’s LAN IP. From the internet, use the public IP (or DNS name) shown on the Server → Network panel.
