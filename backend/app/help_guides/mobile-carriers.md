# Mobile carriers and CGNAT

Some mobile networks are **IPv6-only** or sit behind **CGNAT**, so a phone on cellular data cannot open a connection to a home public IPv4 server — even when Wi‑Fi works fine.

Options:

- Join from **Wi‑Fi** on a network that can reach your host.
- Use a VPN into your LAN.
- Host on a VPS with a real public IP (advanced).

This is a carrier/network limitation, not a MineForge bug.
