# Console basics

Useful commands (player often must be **online**):

- `list` — who is online
- `op <player>` / `deop <player>` — operator (player online)
- `give <player> ...` — items (player online)
- `tp <player> ...` — teleport
- `gamerule <rule> <value>` — world rules

Use the live Console page to send commands. Gamertags must match allowlist entries exactly (including suffixes).
